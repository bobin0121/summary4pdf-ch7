# PDF 요약 웹 앱 설계

- 기준 문서: `docs/prd.md`(F1~F14). 이 설계는 PRD를 따르고, PRD의 열린 질문(10장)에 답한다.
- 개정: 2026-11-26 PRD와 대조해 화면 문구, 오류 제목과 버튼, 시간 초과 안내, 영역 밖 놓기, 용어 원어 병기를 PRD에 맞춤.
- 표시: [사용자 결정]은 사용자가 정한 것, [설계자 판단]은 설계에서 정한 세부 사항이다.

## 1. 한 장면

시험 전날 대학생이 강의 PDF를 화면에 끌어다 놓는다. 1분쯤 기다리면 맨 위에 한 줄 요약이 크게 보이고, 그 아래 핵심 개념 3~5개와 정의, 공식이 이어진다. 원문이 영어여도 요약은 한국어다. 학생은 그걸 보며 무엇부터 공부할지 정한다. [사용자 결정]

## 2. 기술 구성

| 영역 | 선택 |
|---|---|
| 앱 | Next.js 16(App Router, TypeScript), 한 저장소에 화면과 API [사용자 결정] |
| PDF 글자 추출 | `unpdf`(서버리스에서 도는 pdf.js 기반) [설계자 판단] |
| AI | OpenRouter `nvidia/nemotron-3-ultra-550b-a55b:free` → 실패하면 `nvidia/nemotron-3.5-super-vl:free` [사용자 결정] (두 모델 모두 2026-11-26 무료 목록 확인) |
| 시험 | vitest |
| 배포 | 깃허브 `summary4pdf-ch7`(공개), 새 Vercel 프로젝트, Hobby(무료) [사용자 결정] |
| DB, 로그인 | 없음(PRD 범위 밖) |

## 3. 화면 흐름(한 페이지 상태 전환)

화면 문구는 PRD 5장을 글자 그대로 따른다(개정 2026-11-26: 처음 설계의 해요체 문구를 PRD의 합니다체로 맞춤).

1. 업로드: "PDF 요약" 제목, PRD 5.1의 한 줄 설명, 끌어다 놓기 영역(누르면 PDF만 보이는 파일 선택, Enter와 Space로도 열림, 끌고 올라가면 "놓으면 올라갑니다."), 제한 안내, 저장 안내 "올린 파일은 저장되지 않습니다."(F14), 외부 AI 전달 안내 한 줄. 업로드 영역 밖에 놓아도 브라우저가 파일을 열지 않게 창 전체에서 끌어다 놓기 기본 동작을 막는다(F1).
2. 진행: 파일 이름과 크기, PRD 5.2의 진행 문구, 지난 초(시간 약속이 아니라 멈추지 않았음을 보여 주는 용도) [설계자 판단], 30초가 지나면 PRD 5.2의 보조 문구, 취소 단추.
3. 결과: 파일 이름, 한 줄 요약(크게), 핵심 개념(이름과 짧은 설명), 중요한 정의와 공식(공식은 일반 글자, 고정폭 글꼴), "다른 PDF 올리기" 단추, 하단 안내. 정의가 없으면 PRD 5.3의 문구.
4. 오류: PRD 5.4 표의 제목, 문구, 버튼을 오류마다 그대로 보여 준다. 파일 문제는 "다시 올리기", AI와 네트워크 문제는 "다시 시도"(같은 파일)와 업로드로 돌아가는 단추.

## 4. 처리 흐름(`POST /api/summarize`)

1. 브라우저가 먼저 형식과 크기를 검사한다(빠른 안내). 서버가 다시 검사한다.
2. 크기 4MB 초과 → 413 `FILE_TOO_LARGE`. [사용자 결정] (Vercel 함수 요청 본문 한도 4.5MB보다 작게)
3. 확장자와 파일 앞부분(`%PDF-`)을 확인해 PDF가 아니면 415 `NOT_PDF`.
4. `unpdf`로 글자 추출. 암호가 걸렸거나 깨진 파일은 422 `PDF_UNREADABLE`.
5. 공백을 뺀 글자가 100자 미만이면 422 `NO_TEXT`(스캔본 안내, AI 호출 안 함). [설계자 판단]
6. 긴 PDF는 앞부분 30,000자만 보낸다(나눠 요약하지 않음, 하루 무료 호출을 아끼기 위해). 잘랐으면 결과에 "앞부분만 요약했습니다" 표시. [설계자 판단]
7. 모델 호출: 모델당 전체 경과 25초 제한, 첫 모델이 시간 초과, HTTP 오류, 빈 응답, JSON 형식 오류면 둘째 모델. 둘 다 실패하면 원인에 따라 429 `RATE_LIMITED`(한도 차면 안내만 [사용자 결정]) 또는 504 `TIMEOUT`(시간 초과가 있었으면) 또는 502 `AI_FAILED`. 우선순위는 429, 시간 초과, 그 밖의 실패 순이다(F12).
8. 응답 JSON을 검증, 정규화한다: `oneLine`(문자열), `concepts`(1~5개, `{ name, description }`), `definitions`(0개 이상, `{ term, text }`). 핵심 개념이 3개 미만인 짧은 문서도 허용한다. [설계자 판단]
9. 200 `{ summary, truncated, model }`.
10. 파일과 글자는 서버에 저장하지 않는다(메모리에서만 처리). 로그에 원문, 요약을 남기지 않는다. [사용자 결정: 데이터는 우리 서버에서만]
11. 함수 시간: `maxDuration = 60`. [설계자 판단]

## 5. 오류 코드와 문구

제목, 문구, 버튼은 PRD 5.4와 같다.

| 코드 | 상황 | 제목 | 문구 | 버튼 |
|---|---|---|---|---|
| 415 `NOT_PDF` | PDF가 아님 | 올릴 수 없는 파일입니다 | PDF 파일만 올릴 수 있습니다. 파일 형식을 확인한 뒤 다시 올려 주세요. | 다시 올리기 |
| 413 `FILE_TOO_LARGE` | 4MB 초과 | 파일이 너무 큽니다 | 4MB 이하의 PDF만 올릴 수 있습니다. 필요한 쪽만 나눠서 올려 주세요. | 다시 올리기 |
| 422 `PDF_UNREADABLE` | 깨짐, 암호 | PDF를 열 수 없습니다 | 파일이 손상되었거나 암호가 걸려 있을 수 있습니다. 다른 파일로 시도해 주세요. | 다시 올리기 |
| 422 `NO_TEXT` | 글자 없음 | 글자를 찾을 수 없습니다 | 스캔한 이미지로 된 PDF는 지원하지 않습니다. 글자를 복사할 수 있는 PDF를 올려 주세요. | 다시 올리기 |
| 504 `TIMEOUT` | AI 시간 초과 | 요약이 너무 오래 걸립니다 | AI 응답이 제때 오지 않았습니다. 잠시 뒤 다시 시도해 주세요. | 다시 시도 |
| 429 `RATE_LIMITED` | 무료 한도 | 오늘 쓸 수 있는 요약 횟수를 넘었습니다 | 무료 AI 모델의 호출 한도에 도달했습니다. 나중에 다시 시도해 주세요. | 다시 시도 |
| 502 `AI_FAILED` | 두 모델 실패 | 요약하지 못했습니다 | AI가 올바른 요약을 만들지 못했습니다. 다시 시도하거나 다른 파일로 해 보세요. | 다시 시도 |
| 400 `BAD_REQUEST` | 파일 없음 등(PRD에 없음) | 올릴 수 없는 파일입니다 | 파일을 다시 골라 주세요. | 다시 올리기 |
| (화면) | 네트워크 끊김 | 연결에 실패했습니다 | 인터넷 연결을 확인한 뒤 다시 시도해 주세요. | 다시 시도 |

AI 지시문에는 PRD 4.2 규칙을 넣는다: 영어 전문 용어는 한국어 뒤에 괄호로 원어 병기, 수식과 기호는 원문 그대로.

## 7. 시험

- 단위: PDF 검사(크기, 형식), 글자 없음 판정, 앞부분 자르기, 모델 대체(시간 초과, 429, 빈 응답, 잘못된 JSON), 응답 정규화, API 오류 코드.
- 통합: 샘플 PDF(한국어, 영어, 글자 없음, 4MB 초과)로 API를 불러 확인. 실제 OpenRouter 호출은 하루 한도를 아껴 몇 번만.
- 화면: 내 컴퓨터에서 끌어다 놓기부터 결과까지 직접 확인.

## 8. 열린 질문에 대한 답(PRD 10장)

| 번호 | 질문 | 답 |
|---|---|---|
| 1 | PDF 크기 한도 | 4MB [사용자 결정] |
| 2 | 대기 시간 | 보장하지 않음. 모델당 25초, 합계 50초, 30초 지나면 안내 [설계자 판단] |
| 3 | 글자 없음 기준 | 공백 뺀 100자 미만 |
| 4 | 긴 PDF | 앞부분 30,000자만 |
| 5 | 무료 모델 | 2장 표 |
| 6 | 결과 형식 | 4장 8번의 JSON, 어긋나면 다음 모델 |
| 7 | 개념 3개 미만 | 허용(1~5개) |
| 8 | 공식 | 일반 글자, 고정폭 |
| 9 | 호출 한도 | 한도 차면 안내만 [사용자 결정] |
| 10 | 모바일 | 눌러서 선택만 되어도 됨 |
| 11 | 개인정보 안내 | 업로드 화면 한 줄(파일 저장 안 함, 외부 AI로 전달) |
